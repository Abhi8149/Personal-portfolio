# 1. Executive Summary

## 1.1 Purpose

This PRD defines a portfolio website for **Abhinav Shivkumar Ovhal** — a doer, builder, and aspiring AI innovator at NIT Kurukshetra. Unlike generic portfolio templates, this site is a living system: it *thinks* through its interactions, *connects* ideas visually, and *executes* the narrative of someone who ships real products.

The portfolio must communicate one truth above all else: **Abhinav doesn't just have ideas — he builds them.**

## 1.2 The Identity

```

║  "I'm not a thinker who hopes. I'm a builder who ships."       ║
║                                      — Abhinav Shivkumar      ║
╚══════════════════════════════════════════════════════════════╝
```

- **Core Identity**: The Doer
- **Vision**: Build innovations that revolutionize the world — starting locally with Availo
- **Differentiation**: 40+ repositories, 9+ LLD systems, real products deployed, not just projects
- **Key Proof Points**:
  - Availo: Live on Play Store connecting local shopkeepers to local customers
  - Phishing Detection: Ethereum security system
  - System Design: Real-world architectures (Zomato, Spotify, Payment Gateways)
  - AI/ML: GANs, RAG applications, image detection, research-driven

## 1.3 Design Philosophy

> "The best portfolio isn't one that lists what you've done — it's one that *shows* who you are."

This portfolio operates on **three principles**:

1. **Neural Visualization**: The entire site feels like exploring a neural network — nodes connecting, signals flowing, systems thinking made visible
2. **Proof Over Promises**: Every claim is backed by evidence — live links, deployed products, actual repositories
3. **Human Algorithm**: The perfect blend of systematic thinking (LLD, DSA) and creative execution (design, UX, storytelling)

### Primary Voice: "The Doer Speaks"

This is not a formal resume. This is Abhinav — confident, direct, honest about what he's built and clear about where he's going.

**Voice Characteristics:**

## 3.2 Neural Network Visual Elements

### The Core Metaphor

The portfolio is designed as an **exploration of a neural network** — where Abhinav's skills, projects, and ideas are neurons, and their connections represent relationships, technologies, and impact.

### Visual Components

#### 3.2.1 Neural Particles Background

```
Implementation: Canvas-based animated background
- Particles: Small glowing dots (#6366f1, #8b5cf6, #06b6d4)
- Connections: Faint lines between nearby particles
- Movement: Slow, organic drift with subtle acceleration on scroll
- Density: Medium — visible but not distracting
- Performance: Throttled to 30fps on mobile, 60fps on desktop
```

**Animation Characteristics:**
- Particles never fully stop (always subtle movement)
- Scroll position affects particle velocity (faster scroll = faster particles)
- Hover on interactive elements attracts nearby particles

#### 3.2.2 Node Connection Lines

```
Usage: Connecting skills to projects, projects to impact
- Style: SVG paths with gradient strokes
- Animation: Draw-in effect on scroll intersection
- Color: Gradient from source node color to destination
- Opacity: 0.3 → 0.8 on hover/active
```

#### 3.2.3 Circuit Board Patterns

```
Usage: Section dividers, card backgrounds, decorative elements
- Pattern: Subtle circuit traces in background
- Color: Very faint (#1a1a24 strokes on #0a0a0f background)
- Opacity: 0.05 - 0.1 (barely visible, adds texture)
- Animation: None (static texture element)
```

#### 3.2.4 Signal Flow Indicators

```
Usage: Timeline, progress indicators, skill levels
- Style: Dots with trailing "signal" lines
- Color: Accent gradient
- Animation: Pulse effect, moving from start to end
- Timing: 2s loop, ease-in-out
```

# 5. Animation & Interaction Specification

## 5.1 Animation Philosophy

> "Animations should reveal, not distract. Every motion tells a story."

### Animation Principles

1. **Purpose**: Every animation has a reason — to guide attention, show relationships, or delight
2. **Performance**: 60fps on desktop, 30fps minimum on mobile, never block interaction
3. **Subtlety**: Less is more — a small, well-timed animation beats a constant spectacle
4. **Accessibility**: Respect `prefers-reduced-motion`, provide fallbacks

## 5.2 Animation Specifications

### 5.2.1 Neural Particle Background

```
Type:           Canvas-based particle system
Canvas Layer:   Fixed position, z-index: -1
Performance:    RequestAnimationFrame, auto-throttle

Particles:
  Count:        80-120 (desktop), 40-60 (mobile)
  Size:         2-4px
  Color:        Random from accent palette
  Opacity:      0.3-0.7
  Movement:     Organic drift, 0.1-0.5px per frame

Connections:
  Distance:     100-150px triggers connection
  Line Width:   1px
  Opacity:      0.1-0.3 (based on distance)
  Color:        Gradient between connected particles

Scroll Effect:
  Velocity Multiplier: 1.0 + (scrollSpeed * 0.1)
  Direction: Particles drift in scroll direction slightly
```

### 5.2.2 Scroll-Triggered Animations

```
Scroll Observer: Intersection Observer API

Fade In Up:
  Trigger:     20% of element visible
  Duration:    600ms
  Easing:      cubic-bezier(0.16, 1, 0.3, 1)
  Properties:  opacity 0→1, translateY 30px→0

Stagger Children:
  Delay:       100ms between items
  Max Items:   10 (prevents performance issues)

Draw Lines:
  Trigger:     50% of SVG visible
  Duration:    1000ms
  Easing:      ease-out
  Properties:  stroke-dashoffset 100%→0%

Counter Animation:
  Trigger:     30% of counter visible
  Duration:    2000ms
  Easing:      ease-out
  Properties:  Number counts up from 0
```

### 5.2.3 Hover Interactions

```
Cards:
  Transform:   translateY(-4px)
  Duration:    300ms
  Easing:      ease-out
  Shadow:      Add glow shadow with accent color
  Border:      Border color transitions to accent

Buttons:
  Scale:       1.02
  Duration:    200ms
  Easing:      ease-out
  Background:  Brightness increases to 1.1

Links:
  Color:       Transition to accent color
  Underline:   Slides in from left
  Duration:    200ms

Nav Items:
  Background:  Subtle accent glow appears
  Text:        Brightens to full white
  Duration:    150ms
```

### 5.2.4 Section Transitions

```
Page Load:
  1. Background particles fade in (500ms)
  2. Navigation slides down (400ms, staggered)
  3. Hero text reveals line by line (100ms stagger)
  4. CTA buttons fade up (300ms, after text)

Section Scroll:
  1. Previous section fades slightly (opacity 0.7)
  2. Current section title draws in
  3. Content cards stagger in from bottom
```

### 5.2.5 Micro-Interactions

```
Button Click:
  Scale:  0.98 (press down)
  50ms
  Then:  Scale 1.0 (release)
  100ms

Badge Pulse:
  Animation: Scale 1→1.05→1, opacity 1→0.8→1
  Duration:  2000ms
  Loop:     Infinite, paused on hover

Terminal Cursor:
  Animation: Blink opacity 1→0→1
  Duration:  1000ms
  Timing:    steps(1)
  Loop:      Infinite

Sound Wave (for audio-related content):
  5 bars, random height animation
  Duration: 300-600ms per bar
  Loop:     Infinite
```

### 5.2.6 Loading States

```
Page Load:
  1. Background renders immediately
  2. Nav appears with skeleton
  3. Hero text appears (typed effect optional)
  4. Particles start after 500ms

Image Load:
  1. Show subtle gradient placeholder
  2. Image fades in on load
  Duration: 300ms

API Content (if dynamic):
  Skeleton loader with subtle pulse animation
  Color: #1a1a24 → #252530 alternating
```

## 5.3 Reduced Motion Mode

```
@media (prefers-reduced-motion: reduce) {
  - Particles: Static positions, no animation
  - Scroll animations: Instant, no transition
  - Hover effects: Color change only, no transform
  - Looping animations: Paused
}
```
